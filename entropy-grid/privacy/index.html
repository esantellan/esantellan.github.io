Política de privacidad

Vigente desde: 30 de agosto de 2026

La versión en inglés está disponible más abajo.

1. Responsable

Entropy Grid es desarrollada y publicada por Emiliano Santellan. Para consultas relacionadas con privacidad, escribe a emilianosantellan@gmail.com.

2. Datos almacenados en el dispositivo

La aplicación guarda localmente una cantidad limitada de preferencias y progreso:

  • finalización de la introducción;
  • nombre visible opcional;
  • preferencia de idioma y visualización de números;
  • nivel actual y semilla determinista del nivel.

Estos datos se utilizan únicamente para restaurar la configuración y el progreso del juego.

3. Recopilación y transferencia

La versión actual de Entropy Grid no crea cuentas, no utiliza servicios de analítica o publicidad y no envía datos personales, progreso ni identificadores del dispositivo a servidores del desarrollador o de terceros. La aplicación puede utilizarse sin conexión a Internet.

4. Compartición de datos

Entropy Grid no vende, alquila ni comparte datos personales con terceros.

5. Conservación y eliminación

Las preferencias permanecen en el dispositivo mientras la aplicación esté instalada o hasta que el usuario borre sus datos desde la configuración de Android. Desinstalar la aplicación también elimina estos datos locales.

6. Menores

Entropy Grid no está diseñada específicamente para menores de 13 años y no recopila deliberadamente información personal de menores. Si el alcance o el público objetivo cambia, esta política será revisada antes de publicar esa versión.

7. Seguridad

Al no transmitirse información personal a servicios remotos, los datos descritos permanecen dentro del almacenamiento local administrado por el sistema operativo. Ningún método de almacenamiento puede garantizar seguridad absoluta.

8. Cambios

Esta política se actualizará si Entropy Grid incorpora cuentas, sincronización en la nube, analítica, publicidad u otras funciones que cambien el tratamiento de datos. La fecha publicada arriba indicará la última revisión.

9. Contacto

Para preguntas o solicitudes relacionadas con privacidad: emilianosantellan@gmail.com.

English version

Privacy Policy

Effective date: August 30, 2026

1. Controller

Entropy Grid is developed and published by Emiliano Santellan. For privacy-related questions, contact emilianosantellan@gmail.com.

2. Data stored on the device

The app locally stores a limited set of preferences and progress:

  • onboarding completion;
  • an optional display name;
  • language and number-visibility preferences;
  • the current level and its deterministic seed.

This information is used only to restore game settings and progress.

3. Collection and transfer

The current version of Entropy Grid does not create user accounts, use analytics or advertising services, or transmit personal data, progress, or device identifiers to the developer or third-party servers. The app can be used without an Internet connection.

4. Data sharing

Entropy Grid does not sell, rent, or share personal data with third parties.

5. Retention and deletion

Preferences remain on the device while the app is installed or until the user clears its data through Android settings. Uninstalling the app also removes this local data.

6. Children

Entropy Grid is not specifically directed to children under 13 and does not knowingly collect personal information from children. If its scope or intended audience changes, this policy will be reviewed before that version is released.

7. Security

Because personal information is not transmitted to remote services, the data described remains in local storage managed by the operating system. No storage method can guarantee absolute security.

8. Changes

This policy will be updated if Entropy Grid introduces accounts, cloud synchronization, analytics, advertising, or other features that change its data practices. The effective date above identifies the latest revision.

9. Contact

For privacy questions or requests, contact emilianosantellan@gmail.com.
